# LazyAlphaWeb

Public documentation site for [LazyAlpha](https://github.com/selvaz/LazyAlpha)'s
backtested trading strategy research: context, cited sources, and full,
honest results for every strategy family attempted — including failures.

This site is generated and maintained by an autonomous agent
(`lazyalpha-architecture-agent`'s sibling, `lazyalpha-web-agent`) from
LazyAlpha's own reports and experiment registry. Every published model card
is reviewed by two independent LLMs before publication (an honesty/accuracy
gate), on top of a mechanical verbatim-substring check against the source
report.
